# Scrip — https://scrip.work
#
# A rule on a Solana wallet: a slice of every USDC arrival becomes a tokenised
# stock in the same wallet, with a permanent on-chain receipt.
#
# Scrip is non-custodial by construction. The program holds no user funds. A
# user's USDC and stock sit in token accounts they control; the program holds
# only the rule and writes receipts. Turning the rule off is a token-program
# `revoke` on the user's own account, which the program cannot prevent.
